How to Deploy:
1. Files ko GitHub pe daal de
2. Render.com pe Web Service bana
3. ENV me BOT_TOKEN aur GEMINI_API_KEY add kar
4. Start Command: python main.py

Features:
- Chat: Kuch bhi pucho, Chikuu jaise jawab degi
- Photo: "photo bana de cute girl in saree" bolegi to AI photo generate karegi
- No Commands: Koi /status /users nahi, sirf chat

Example:
User: tum kaun ho?
Bot: Mai Chikuu hu, Khushi, 18 saal ki, Udaipurwati se 💖

User: ek photo bana de meri
Bot: [Photo generate karegi]
